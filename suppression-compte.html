Cette page explique comment demander la suppression de votre compte Partenaire Dozie ainsi que des données qui y sont associées. La suppression est définitive.

  1. Étape 1 : Contactez-nous via WhatsApp ou e-mail (coordonnées ci-dessous).
  2. Étape 2 : Indiquez le numéro de téléphone associé à votre compte.
  3. Étape 3 : Votre compte et vos données seront supprimés sous 7 jours ouvrables.

Quelles données sont supprimées

Lorsque votre demande est traitée, les données suivantes sont supprimées définitivement :

  • le compte ;
  • le profil (nom, téléphone, e-mail, adresse) ;
  • les boutiques et annonces (pour les vendeurs) ;
  • les commandes ;
  • les avis ;
  • les signalements ;
  • les photos et documents.

Données conservées

Certaines données peuvent être conservées temporairement si la loi l'exige. Elles sont ensuite supprimées définitivement une fois ces obligations légales remplies.
